# ふたりが出会うまで

結婚式の待ち時間に楽しむ、スマートフォン向けの参加型絵本ゲームです。

## 遊び方

「絵本をひらく」を押し、新郎・新婦のどちらかを選びます。幼少期から出会い、プロポーズ、結婚式までを、クイズを交えてたどります。どの答えでも先に進めます。

- アプリのインストール不要、音声なし
- 全8場面、約3〜5分
- 進行状況はブラウザに自動保存
- 最後のメッセージは端末内のみ保存（新郎新婦には送信されません）

**現在のお話はすべて仮のエピソードです。** 実際の思い出に差し替えてから結婚式でご利用ください。

## 編集

- `index.html`: 表紙、デザイン、スマートフォン表示
- `story.js`: 物語、クイズ、挿絵、進行と保存

外部ライブラリやビルドは不要です。GitHub Pagesは `main` ブランチのルートを配信します。

## ローカルで確認

Node.jsがある場合:

```sh
node preview.cjs
```

`http://127.0.0.1:4317` を開きます。

## 公開前の確認

スマホのSafariとChromeで両方のルート、クイズ、戻る操作、途中再開を確認してください。QRコードは公開URLが確定してから作成してください。
